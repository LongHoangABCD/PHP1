F Form trong HTML và PHP

Form là một trong những thành phần quan trọng nhất của website động. Nó cho phép người dùng tương tác và gửi dữ liệu lên server để xử lý.

1. Form là gì? Vai trò của Form

  • Form là một vùng chứa (container) cho phép người dùng nhập dữ liệu.
  • Dùng để thu thập thông tin: đăng ký, đăng nhập, liên hệ, đặt hàng, bình luận, upload file...
  • Là cầu nối giữa Client (trình duyệt) và Server (PHP).

2. Cấu trúc cơ bản của Form 

<form action="xuly.php" method="POST" enctype="multipart/form-data">
    <!-- Các input, textarea, select... -->
    <button type="submit">Gửi dữ liệu</button>
</form>

3. Hai thuộc tính quan trọng: action và method

action

Đường dẫn file PHP sẽ nhận và xử lý dữ liệu từ form.

  • • Nếu để trống hoặc không ghi: gửi về chính trang hiện tại.
  • • Ví dụ: action="register.php"

method

Phương thức gửi dữ liệu:

GET — Dữ liệu hiện rõ trên URL (dùng cho tìm kiếm, lọc)
POST — Dữ liệu gửi trong body (ẩn, an toàn hơn, dùng cho đăng ký, đăng nhập...)

4. Upload File - Thuộc tính enctype

Khi form có upload file, bắt buộc phải dùng: 

<form action="upload.php" method="POST" enctype="multipart/form-data">

Nếu không có enctype="multipart/form-data", file sẽ không được gửi lên server.

S Session trong PHP

Session là cách lưu trữ dữ liệu tạm thời của người dùng trên server trong suốt quá trình họ duyệt website.

1. Session là gì?

  • Session là phiên làm việc của người dùng với website.
  • Dữ liệu được lưu trên Server, không phải trên trình duyệt của người dùng.
  • Mỗi người dùng sẽ có một Session ID riêng biệt.
  • Session thường dùng để lưu thông tin đăng nhập, giỏ hàng, quyền truy cập...

2. So sánh Cookie và Session

Tiêu chí Cookie Session
Nơi lưu trữ Trình duyệt (Client) Server
Dung lượng Rất nhỏ (khoảng 4KB) Lớn hơn nhiều
Bảo mật Thấp (dễ bị xem, sửa) Cao hơn
Thời gian tồn tại Tùy chỉnh (có thể vĩnh viễn) Hết khi đóng trình duyệt hoặc timeout
Ứng dụng Nhớ tên, ngôn ngữ, tùy chọn Đăng nhập, giỏ hàng, quyền user

3. Quy trình hoạt động chi tiết của Session

1
Khi người dùng truy cập website:
PHP tự động tạo một Session ID (một chuỗi ngẫu nhiên dài).
2
Server lưu Session:
Dữ liệu Session được lưu trên server (thường trong thư mục tmp hoặc database).
3
Gửi Session ID về Client:
PHP gửi Session ID về trình duyệt qua Cookie (tên mặc định là PHPSESSID).
4
Các lần truy cập sau:
Trình duyệt gửi lại PHPSESSID trong Cookie → Server lấy Session ID đó để khôi phục dữ liệu Session.

4. Ví dụ thực tế: Hệ thống Đăng nhập sử dụng Session

Quy trình Đăng nhập với Session (Timeline)

1
Người dùng nhập thông tin và Submit form 
<form action="login.php" method="POST">
    Username: <input type="text" name="username">
    Password: <input type="password" name="password">
</form>
2
Server (login.php) nhận dữ liệu và kiểm tra 
if (username và password đúng) {
    // Tiến hành tạo session
}
3
Khởi tạo Session & Lưu thông tin 
session_start();

$_SESSION['user_id']   = 15;
$_SESSION['username']  = "nguyenvanA";
$_SESSION['role']      = "sinhvien";
$_SESSION['login_time'] = time();
4
PHP tự động tạo và gửi Session ID về Client

Server tạo PHPSESSID và gửi về trình duyệt qua Cookie.

5
Chuyển hướng sang trang Dashboard 
header("Location: dashboard.php");
exit();
6
Các lần truy cập sau

Trình duyệt tự động gửi PHPSESSID trong Cookie → Server dùng ID này để khôi phục $_SESSION

Code đầy đủ login.php

<?php
session_start();

if ($_SERVER['REQUEST_METHOD'] == 'POST') {
    $username = $_POST['username'];
    $password = $_POST['password'];

    // Giả sử kiểm tra thành công
    if ($username === "admin" && $password === "123456") {
        
        $_SESSION['user_id'] = 1;
        $_SESSION['username'] = $username;
        $_SESSION['fullname'] = "Nguyễn Văn A";
        $_SESSION['role'] = "admin";

        header("Location: dashboard.php");
        exit();
    } else {
        echo "Sai tài khoản hoặc mật khẩu!";
    }
}
?>

5. Các hàm Session thường dùng

session_start()
Khởi tạo hoặc khôi phục session
$_SESSION['key'] = value;
Lưu dữ liệu vào session
unset($_SESSION['key']);
Xóa một biến session
session_destroy();
Xóa toàn bộ session (đăng xuất)

Ứng dụng thực tế của Form và Session

Ứng dụng của Form

  • • Form Đăng ký / Đăng nhập thành viên
  • • Form Liên hệ, Góp ý, Hỗ trợ khách hàng
  • • Form Đặt hàng, Thanh toán (E-commerce)
  • • Form Upload ảnh, tài liệu, CV
  • • Form Tìm kiếm, Lọc sản phẩm, Bài viết
  • • Form Khảo sát, Bình chọn, Đánh giá

Ứng dụng của Session

  • • Giữ trạng thái đăng nhập (Login persistence)
  • • Quản lý Giỏ hàng mua sắm
  • • Lưu thông tin cá nhân hóa (Tên, Quyền truy cập)
  • • Kiểm soát quyền truy cập (Authorization)
  • • Lưu dữ liệu tạm thời (Multi-step form)
  • • Ngăn chặn đăng nhập trùng (Session timeout)

Các tính năng thường kết hợp Form + Session

  • → Đăng ký tài khoản → Kiểm tra form → Lưu thông tin vào Session → Chuyển hướng
  • → Thêm sản phẩm vào giỏ hàng (Form + Session)
  • → Form đặt hàng nhiều bước (Multi-step Form) dùng Session để lưu tạm dữ liệu
  • → Hệ thống Comment / Bình luận sau khi đăng nhập
  • → Form chỉnh sửa thông tin cá nhân (Profile)
  • → Hệ thống quản trị Admin (Dashboard)
