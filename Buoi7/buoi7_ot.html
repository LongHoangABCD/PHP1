1 Tính Kế Thừa (Inheritance) là gì?

Tính kế thừa là tính chất cho phép một lớp (class con) kế thừa thuộc tính và phương thức từ một lớp khác (class cha). Nhờ đó, chúng ta có thể tái sử dụng code một cách hiệu quả.

Mục tiêu chính:

  • Tái sử dụng code (Code Reusability)
  • Tạo ra mối quan hệ phân cấp (is-a relationship)
  • Dễ dàng bảo trì và mở rộng hệ thống

2 Cú pháp kế thừa trong PHP

Sử dụng từ khóa extends để kế thừa:

<?php
class Cha {
    // thuộc tính và phương thức
}

class Con extends Cha {
    // Con kế thừa tất cả thuộc tính và phương thức public/protected của Cha
}
?>

4 Ví dụ cơ bản

Dưới đây là ví dụ minh họa cơ bản về Tính Kế Thừa trong PHP:

Code ví dụ:

<?php
class Person {
    protected $name;
    protected $age;

    public function setInfo($name, $age) {
        $this->name = $name;
        $this->age  = $age;
    }

    public function showInfo() {
        echo "Tên: $this->name, Tuổi: $this->age";
    }
}

class Student extends Person {
    private $studentId;

    public function setStudentId($id) {
        $this->studentId = $id;
    }

    public function showInfo() {
        parent::showInfo(); // Gọi phương thức của class cha
        echo " - Mã SV: $this->studentId";
    }
}

$sv = new Student();
$sv->setInfo("Hoàng Long", 21);
$sv->setStudentId("SV001");
$sv->showInfo();
?>
Phân tích chi tiết ví dụ:

1. Class cha (Person):

  • Khai báo hai thuộc tính protected $name và protected $age: Cho phép class con (Student) truy cập được.
  • Có hai phương thức public: setInfo() và showInfo().

2. Class con (Student):

  • Sử dụng từ khóa extends Person để kế thừa từ class cha.
  • Thêm thuộc tính riêng private $studentId.
  • Ghi đè (Override) phương thức showInfo() của class cha.
  • Sử dụng parent::showInfo() để gọi phương thức của class cha trước khi bổ sung thông tin riêng.

3. Kết quả khi chạy:

Tên: Hoàng Long, Tuổi: 21 - Mã SV: SV001

4. Lợi ích thể hiện trong ví dụ:

  • Tái sử dụng code: Không cần viết lại setInfo() và logic hiển thị tên, tuổi.
  • Mở rộng dễ dàng: Class Student chỉ cần thêm những gì riêng của nó.
  • Phương thức ghi đè (Overriding): Class con có thể thay đổi hành vi của phương thức cha.
  • Sử dụng parent::: Giúp gọi lại phương thức gốc của class cha khi cần.

Kết luận: Đây là cách thể hiện rõ nhất mối quan hệ "is-a" (Student là một Person). Tính kế thừa giúp code ngắn gọn, dễ quản lý và dễ mở rộng.

5 Ví dụ thực tế: Hệ thống quản lý phương tiện giao thông

Đây là ví dụ thực tế minh họa rõ nét lợi ích của Tính Kế Thừa khi xây dựng hệ thống có nhiều đối tượng có điểm chung.

Code ví dụ:

<?php
class Vehicle {
    protected $brand;
    protected $speed = 0;

    public function __construct($brand) {
        $this->brand = $brand;
    }

    public function accelerate($amount) {
        $this->speed += $amount;
        echo "$this->brand tăng tốc lên $this->speed km/h\n";
    }
}

class Car extends Vehicle {
    private $doors;

    public function __construct($brand, $doors) {
        parent::__construct($brand); // Gọi constructor của class cha
        $this->doors = $doors;
    }

    public function honk() {
        echo "Beep Beep! Xe $this->brand đang bấm còi.\n";
    }
}

class Motorcycle extends Vehicle {
    public function wheelie() {
        echo " $this->brand đang làm wheelie!\n";
    }
}

// Sử dụng
$myCar = new Car("Toyota", 4);
$myCar->accelerate(60);
$myCar->honk();

$moto = new Motorcycle("Honda");
$moto->accelerate(40);
$moto->wheelie();
?>
Phân tích chi tiết ví dụ:

1. Class cha (Vehicle):

  • Chứa các thuộc tính và phương thức chung cho tất cả phương tiện: $brand, $speed, và phương thức accelerate().
  • Sử dụng protected cho thuộc tính để class con có thể truy cập.
  • Có constructor nhận tham số $brand.

2. Class con (Car và Motorcycle):

  • Car kế thừa từ Vehicle và bổ sung thuộc tính riêng $doors.
  • Motorcycle kế thừa từ Vehicle và bổ sung phương thức riêng wheelie().
  • Cả hai đều gọi parent::__construct($brand) để khởi tạo thuộc tính của class cha.

3. Kết quả khi chạy chương trình: 

Toyota tăng tốc lên 60 km/h
Beep Beep! Xe Toyota đang bấm còi.
Honda tăng tốc lên 40 km/h
=> Honda đang làm wheelie!

4. Lợi ích nổi bật của Tính Kế Thừa:

  • Tái sử dụng code cao: Phương thức accelerate() chỉ viết một lần nhưng dùng được cho cả xe hơi và xe máy.
  • Dễ mở rộng hệ thống: Muốn thêm lớp Truck, Bus, hay ElectricCar chỉ cần kế thừa từ Vehicle và thêm tính năng riêng.
  • Code sạch và dễ bảo trì: Logic chung được tập trung ở class cha, tránh lặp code.
  • Thể hiện mối quan hệ "is-a": Car is a Vehicle, Motorcycle is a Vehicle.

Kết luận: Tính Kế Thừa giúp chúng ta xây dựng hệ thống theo kiểu phân cấp tự nhiên, giảm thiểu lặp code và tăng khả năng mở rộng — đây là một trong những lợi thế quan trọng nhất của lập trình hướng đối tượng.
