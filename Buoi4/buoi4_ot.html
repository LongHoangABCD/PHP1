1 OOP là gì?

Lập trình hướng đối tượng (Object-Oriented Programming - OOP) là một phong cách lập trình coi mọi thứ trong chương trình là các "đối tượng" (object).

OOP mô phỏng thế giới thực: mỗi vật thể đều có thuộc tính (attributes/properties) và hành vi (methods).

💡 OOP là phong cách chung, không phải “của PHP”

Bạn có thể áp dụng OOP trong rất nhiều ngôn ngữ khác nhau. PHP chỉ là một trong số đó.

Các phong cách lập trình chính

  • Procedural Programming (C, PHP cũ): Tập trung vào hàm và thủ tục
  • Object-Oriented Programming (PHP, Java, C#, Python...): Tập trung vào đối tượng
  • Functional Programming: Tập trung vào hàm thuần túy

So sánh

Procedural Code theo thứ tự, dùng hàm
OOP Code theo đối tượng, dễ quản lý code lớn, dễ mở rộng, dễ bảo trì, dễ tái sử dụng các đoạn code

Phân loại ngôn ngữ theo OOP

Ngôn ngữ thuần OOP (Pure OOP)

Là ngôn ngữ buộc phải sử dụng OOP trong hầu hết code. Không (hoặc rất hạn chế) cho phép viết theo kiểu procedural.

  • Java — Rất nghiêm ngặt với OOP
  • C# — Thuần OOP
  • Smalltalk — Ngôn ngữ đầu tiên áp dụng OOP
  • Ruby — Gần như thuần OOP

Ngôn ngữ hỗ trợ OOP (Multi-paradigm)

Là ngôn ngữ cho phép sử dụng nhiều phong cách lập trình khác nhau (OOP, Procedural, Functional…) tùy theo nhu cầu.

  • PHP — Hỗ trợ OOP (từ phiên bản 5 trở lên)
  • Python — Hỗ trợ mạnh OOP
  • JavaScript — Dùng prototype-based OOP
  • C++ — Hỗ trợ cả Procedural và OOP
  • TypeScript — Tăng cường OOP cho JavaScript

2 Ưu và nhược điểm của OOP

Ưu điểm

  • Tái sử dụng code cao (Inheritance, Polymorphism)
  • Dễ bảo trì và mở rộng
  • Code rõ ràng, có cấu trúc
  • Dễ làm việc nhóm

Nhược điểm

  • Khúc đầu khó học hơn
  • Code dài hơn một chút
  • Hiệu năng thấp hơn chút so với Procedural (trong PHP)
  • Dễ lạm dụng, dẫn đến over-engineering

3 Class là gì?

Class là bản thiết kế (blueprint) ~ hay khuôn mẫu để tạo ra các đối tượng.

Từ một class (1 bản thiết kế) có thể tạo ra nhiều đối tượng khác nhau.

Ví dụ: Từ một bản thiết kế ngôi nhà chung: có thể tạo ra ngôi nhà của bạn Lan (nhà cấp 4), có thể tạo ra nhà của bạn Mai (nhà chung cư), có thể tạo ra nhà của bạn Hùng (nhà biệt thự)

=> Đặc điểm chung của chúng đều là các ngôi nhà (Đều được tạo ra từ class) 

<?php
class User {
    // Thuộc tính (properties / attributes)
    public $name;
    public $email;
    private $password;
    
    // Phương thức (methods)
    public function register() {
        // logic đăng ký
    }
    
    public function login() {
        // logic đăng nhập
    }
}
?>

4 Object là gì?

Object là thực thể (instance) được tạo ra từ Class. 

<?php
// Tạo object từ class
$user1 = new User();
$user1->name = "Nguyễn Văn A";
$user1->email = "a@gmail.com";

$user2 = new User();
$user2->name = "Trần Thị B";
?>

5 Các thành phần chính trong Class

1. Properties / Attributes (Thuộc tính)

Properties là các biến mô tả đặc điểm, trạng thái của đối tượng.

Ví dụ: Một đối tượng Student có thể có thuộc tính: name, age, studentId, email...

Quy tắc đặt tên Properties trong PHP:

  • • Bắt đầu bằng chữ cái hoặc dấu gạch dưới (_)
  • • Thường dùng camelCase: $firstName, $studentId
  • • Có thể dùng snake_case: $first_name (PHP chấp nhận cả hai)
  • • Nên có tính mô tả rõ ràng, dễ hiểu, thường sẽ là các danh từ

Phạm vi truy cập: public • protected • private

2. Methods (Phương thức)

Methods là các hàm bên trong class, dùng để định nghĩa hành vi, hành động của đối tượng.

Ví dụ: register(), login(), calculateGPA(), getInfo()...

Quy tắc đặt tên Methods trong PHP:

  • • Bắt đầu bằng chữ cái thường
  • • Thường dùng camelCase: getUserInfo(), updateProfile()
  • • Tên method nên là động từ hoặc hành động
  • • Rõ ràng, mô tả được công việc method đó làm

Methods cũng có thể có phạm vi truy cập: public, protected, private

Ví dụ thực tế đầy đủ

<?php
class Student {
    public $id;
    public $name;
    public $age;
    private $gpa;

    // Constructor
    public function __construct($id, $name, $age) {
        $this->id = $id;
        $this->name = $name;
        $this->age = $age;
        $this->gpa = 0.0;
    }

    public function setGPA($gpa) {
        if ($gpa >= 0 && $gpa <= 4.0) {
            $this->gpa = $gpa;
        }
    }

    public function getInfo() {
        return "MSSV: $this->id - $this->name ($this->age tuổi)";
    }
}

// Sử dụng
$sv1 = new Student("SV001", "Phạm Thị Hương", 20);
$sv1->setGPA(3.5);

echo $sv1->getInfo();
?>
