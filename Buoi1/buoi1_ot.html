3 Cấu trúc điều khiển (Control Structures)

1. if ... else

Lý thuyết: Dùng để thực thi khối lệnh khi điều kiện đúng (true) và khối lệnh khác khi sai (false). 

if (điều_kiện) {
    // code khi đúng
} elseif (điều_kiện_2) {
    // code khi điều kiện 2 đúng
} else {
    // code khi tất cả sai
}

2. switch ... case

Lý thuyết: Dùng để so sánh một biến với nhiều giá trị khác nhau. 

switch ($bien) {
    case gia_tri_1:
        // lệnh
        break;
    default:
        // lệnh mặc định
}

Bài tập ứng dụng (Cấu trúc điều khiển)

  1. Bài 1: Nhập một số nguyên, kiểm tra chẵn hay lẻ.
  2. Bài 2: Nhập điểm trung bình (0-10), phân loại học lực (Xuất sắc, Giỏi, Khá, Trung bình, Yếu).
  3. Bài 3: Nhập tháng (1-12), in ra số ngày của tháng đó (không nhuận).

4 Vòng lặp (Loops)

1. for

for ($i = 1; $i <= 10; $i++) {
    echo $i;
}

2. while

while (điều_kiện) {
    // code
}

3. do...while 

do {
    // code
} while (điều_kiện);

Bài tập ứng dụng (Vòng lặp)

  1. Bài 1: In bảng cửu chương 5 (từ 1 đến 10) dùng for.
  2. Bài 2: Tính tổng các số chẵn từ 1 đến 100 dùng while.
