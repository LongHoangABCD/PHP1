3 Cấu trúc điều khiển (Control Structures)

1. if ... else

Lý thuyết: Dùng để thực thi khối lệnh khi điều kiện đúng (true) và khối lệnh khác khi sai (false). 


  if ($điều_kiện) {
      // code khi đúng
  } else if ($điều_kiện_2) {
      // code khi điều kiện 2 đúng
  } else {
      // code khi tất cả sai
  }
Truthy và Falsy trong PHP

Trong PHP, điều kiện trong if không bắt buộc phải là true hoặc false. PHP sẽ tự động chuyển đổi giá trị sang kiểu boolean.

Falsy là các giá trị được xem là false: 

false
          0
          0.0
          ""
          "0"
          []
          null

Truthy là các giá trị còn lại, ví dụ: 

true
          1
          -5
          "hello"
          [1, 2, 3]
          new stdClass()

Ví dụ:

$username = "";

          if ($username) {
              echo "Có username";
          } else {
              echo "Không có username";
          }

Vì "" là giá trị falsy, nên chương trình sẽ chạy vào khối else.

2. switch ... case

Lý thuyết: Dùng để so sánh một biến với nhiều giá trị khác nhau. 

switch ($bien) {
    case gia_tri_1:
        // code chạy khi $bien = gia_tri_1
        break;
    case gia_tri_2:
        // code chạy khi $bien = gia_tri_2
        break;
    default:
        // code mặc định (chạy khi $bien không bằng bất kỳ case nào bên trên)
}

break: dùng để dừng switch sau khi thực thi xong một case. Nếu không có break, chương trình sẽ tiếp tục chạy các case phía dưới dù điều kiện không khớp. Điều này gọi là fall-through.

4 Vòng lặp (Loops)

1. for

Lý thuyết: Vòng lặp for thường được dùng khi biết trước số lần lặp. Nó gồm 3 phần:

  • Khởi tạo biến đếm
  • Điều kiện lặp
  • Tăng / giảm biến đếm sau mỗi lần lặp
for ($i = 1; $i <= 10; $i++) {
              echo $i;
          }

2. while

Lý thuyết: Vòng lặp while sẽ kiểm tra điều kiện trước. Nếu điều kiện đúng thì code mới được thực thi.

Nếu điều kiện sai ngay từ đầu thì vòng lặp sẽ không chạy lần nào. 

$i = 1;

          while ($i <= 5) {
              echo $i;
              $i++;
          }

3. do...while

Lý thuyết: Vòng lặp do...while sẽ chạy code trước, sau đó mới kiểm tra điều kiện.

Vì vậy vòng lặp này luôn chạy ít nhất 1 lần dù điều kiện sai. 

$i = 1;

          do {
              echo $i;
              $i++;
          } while ($i <= 5);

4. break

Lý thuyết: break dùng để thoát khỏi vòng lặp ngay lập tức.

Khi gặp break, chương trình sẽ dừng vòng lặp hiện tại. 

for ($i = 1; $i <= 10; $i++) {

              if ($i == 5) {
                  break;
              }

              echo $i;
          }

5. continue

Lý thuyết: continue dùng để bỏ qua lần lặp hiện tại và chuyển sang lần lặp tiếp theo. 

for ($i = 1; $i <= 5; $i++) {

              if ($i == 3) {
                  continue;
              }

              echo $i;
          }

Bài tập ứng dụng (Vòng lặp)

  1. Lời giải 

    <?php

              for ($i = 1; $i <= 10; $i++) {
                  echo "5 x $i = " . (5 * $i) . "<br>";
              }
    Giải thích
    • $i = 1: Khởi tạo biến bắt đầu từ 1
    • $i <= 10: Lặp đến khi i nhỏ hơn hoặc bằng 10
    • $i++: Tăng i lên 1 sau mỗi lần lặp
    • (5 * $i): Tính kết quả phép nhân

  2. Lời giải 

    <?php

                $i = 2;
                $sum = 0;

                while ($i <= 100) {
                    $sum += $i;
                    $i += 2;
                }

                echo "Tổng các số chẵn từ 1 đến 100 là: " . $sum;
    Giải thích
    • $i = 2: Bắt đầu từ số chẵn đầu tiên
    • $sum = 0: Biến dùng để lưu tổng
    • while ($i <= 100): Lặp khi i còn nhỏ hơn hoặc bằng 100
    • $sum += $i: Cộng giá trị hiện tại của i vào tổng
    • $i += 2: Tăng thêm 2 để sang số chẵn tiếp theo
