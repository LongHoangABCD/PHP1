$this Biến $this trong OOP

$this là một biến đặc biệt (pseudo-variable) trong PHP OOP. Nó đại diện cho đối tượng hiện tại (instance) đang được thao tác.

Ý nghĩa:

$this cho phép bạn truy cập đến thuộc tính và phương thức của chính đối tượng đó từ bên trong class.

Ví dụ minh họa:

<?php
class Student {
    public $name;
    public $age;

    public function setInfo($name, $age) {
        $this->name = $name;   // $this chỉ đến đối tượng hiện tại
        $this->age  = $age;
    }

    public function showInfo() {
        echo "Tên: " . $this->name . " - Tuổi: " . $this->age;
    }
}

$sv = new Student();
$sv->setInfo("Long", 21);
$sv->showInfo();
?>

Lưu ý: $this chỉ có thể sử dụng bên trong class. Không thể dùng $this ở bên ngoài class.

1 Constructor (Phương thức khởi tạo)

Constructor là phương thức đặc biệt được gọi tự động ngay khi tạo ra một đối tượng từ class.

Mục đích: Khởi tạo giá trị ban đầu cho thuộc tính và thực hiện các thiết lập cần thiết.

Đặc điểm:

  • Tên: __construct()
  • Có thể có tham số
  • Không có kiểu trả về: (không có return)

Ví dụ:

<?php
class Student {
    public $id;
    public $name;
    public $age;

    public function __construct($id, $name, $age) {
        $this->id   = $id;
        $this->name  = $name;
        $this->age   = $age;
        
        echo "Đối tượng Student đã được tạo!
";
    }
}

$sv1 = new Student("SV001", "Nguyễn Văn A", 20);
?>

2 Destructor (Phương thức huỷ)

Destructor là phương thức được gọi tự động khi đối tượng bị huỷ khỏi bộ nhớ.

Mục đích: Dọn dẹp tài nguyên (đóng file, đóng kết nối database, giải phóng bộ nhớ...).

Khi nào một Object bị huỷ?

  • 1. Khi script PHP chạy xong (kết thúc file)
  • 2. Khi biến chứa object ra khỏi phạm vi (out of scope)
  • 3. Khi gán null hoặc dùng hàm unset($object)
  • 4. Khi không còn bất kỳ biến nào tham chiếu đến object đó (Garbage Collection)

💡 Trong thực tế, Destructor thường được dùng để đóng kết nối database hoặc file.

Đặc điểm:

  • Tên: __destruct()
  • Không có tham số
  • Không có kiểu trả về: (không có return)

Ví dụ minh họa:

<?php
class Connection {
    public function __construct() {
        echo "🔗 Kết nối Database thành công!
";
    }

    public function __destruct() {
        echo " Đã đóng kết nối Database.
";
    }
}

// Tạo object
$db = new Connection();

echo "Đang thực hiện công việc...
";

// Kết thúc script → Destructor tự động chạy
?>
