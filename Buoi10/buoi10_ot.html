1 Khái niệm MySQL

MySQL là một hệ quản trị cơ sở dữ liệu quan hệ (RDBMS) mã nguồn mở phổ biến nhất thế giới. Nó sử dụng ngôn ngữ SQL (Structured Query Language) để quản lý dữ liệu.

Đặc điểm nổi bật của MySQL:

  • Miễn phí (mã nguồn mở) và dễ cài đặt
  • Hỗ trợ rất tốt với PHP (được thiết kế để kết hợp hoàn hảo)
  • Khả năng mở rộng cao, phù hợp từ dự án nhỏ đến lớn
  • Hỗ trợ nhiều kiểu dữ liệu, index, transaction, stored procedure
  • Được sử dụng bởi nhiều công ty lớn: Facebook, Netflix, Airbnb, YouTube...

2 Ưu điểm và Nhược điểm của MySQL khi kết nối với PHP

Ưu điểm

  • ✓ Tốc độ nhanh và hiệu suất cao với PHP
  • ✓ Dễ học, tài liệu phong phú
  • ✓ Hỗ trợ transaction, foreign key, indexing tốt
  • ✓ Chi phí thấp (miễn phí)
  • ✓ Cộng đồng lớn, dễ tìm giải pháp

Nhược điểm

  • ✗ Không mạnh bằng PostgreSQL về concurrency lớn
  • ✗ Hiệu suất giảm rõ khi dữ liệu rất lớn (terabytes)
  • ✗ Cần cấu hình tốt để đảm bảo an ninh
  • ✗ Không linh hoạt bằng NoSQL với dữ liệu không cấu trúc

3 Các cách kết nối MySQL với PHP

PHP cung cấp 3 cách chính để kết nối với MySQL. Mỗi cách có cách viết và mức độ phù hợp khác nhau.

1 mysqli (Procedural Style)

Đây là cách truyền thống, sử dụng các hàm có tiền tố mysqli_. Phù hợp cho người mới học vì cú pháp đơn giản, dễ hiểu. 

<?php
$servername = "localhost";
$username = "root";
$password = "";
$dbname = "php_mvc";

// Tạo kết nối
$conn = mysqli_connect($servername, $username, $password, $dbname);

// Kiểm tra kết nối
if (!$conn) {
    die("Kết nối thất bại: " . mysqli_connect_error());
}

echo "Kết nối thành công!";
?>

Cách hoạt động: Hàm mysqli_connect() trả về một đối tượng kết nối hoặc false nếu thất bại.

2 mysqli (Object-Oriented)

Cách này sử dụng lập trình hướng đối tượng, code gọn và dễ quản lý hơn so với Procedural. 

<?php
$conn = new mysqli("localhost", "root", "", "php_mvc");

if ($conn->connect_error) {
    die("Kết nối thất bại: " . $conn->connect_error);
}

echo "Kết nối thành công!";
?>

3 PDO (PHP Data Objects) Khuyến nghị sử dụng

PDO là lớp trừu tượng (abstraction layer), cho phép bạn kết nối với nhiều loại database khác nhau (MySQL, PostgreSQL, SQLite...) chỉ bằng cách thay đổi DSN. 

<?php
try {
    $pdo = new PDO(
        "mysql:host=localhost;dbname=php_mvc;charset=utf8mb4", 
        "root", 
        "",
        [
            PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,      // Bật exception khi có lỗi
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC, // Trả về mảng kết hợp
            PDO::ATTR_EMULATE_PREPARES => false               // Sử dụng Prepared Statement thật
        ]
    );
} catch(PDOException $e) {
    die("Lỗi kết nối: " . $e->getMessage());
}
?>

Bảng so sánh các cách kết nối

Tại sao nên sử dụng PDO?

  • - Hỗ trợ nhiều hệ quản trị CSDL: Dễ dàng chuyển sang PostgreSQL, SQL Server sau này mà không phải viết lại code.
  • - An toàn hơn: Hỗ trợ Prepared Statements tốt, giảm nguy cơ SQL Injection.
  • - Xử lý lỗi chuyên nghiệp: Sử dụng Exception giúp code sạch và dễ debug.
  • - Linh hoạt và hiện đại: Là cách tiếp cận được khuyến nghị chính thức của PHP cho các dự án mới.

4 Áp dụng trong mô hình MVC

Trong mô hình MVC, việc kết nối Database thường được đặt trong Model. Controller sẽ gọi Model để thực hiện các thao tác dữ liệu.

Cấu trúc thư mục gợi ý

project/
├── config/
│   └── database.php
├── app/
│   ├── Models/
│   │   └── User.php
│   ├── Controllers/
│   │   └── UserController.php
│   └── Views/
│       └── users/
└── public/
    └── index.php

1. config/database.php 

<?php
class Database {
    private $host = "localhost";
    private $db_name = "php_mvc";
    private $username = "root";
    private $password = "";
    public $conn;

    public function getConnection() {
        $this->conn = null;
        try {
            $this->conn = new PDO(
                "mysql:host=" . $this->host . ";dbname=" . $this->db_name . ";charset=utf8mb4",
                $this->username,
                $this->password
            );
            $this->conn->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
            $this->conn->setAttribute(PDO::ATTR_DEFAULT_FETCH_MODE, PDO::FETCH_ASSOC);
        } catch(PDOException $e) {
            echo "Lỗi kết nối Database: " . $e->getMessage();
        }
        return $this->conn;
    }
}
?>

2. app/Models/User.php 

<?php
class User {
    private $conn;
    private $table = "users";

    public function __construct($db) {
        $this->conn = $db;
    }

    // Lấy tất cả users
    public function getList() {
        $sql = "SELECT * FROM " . $this->table . " ORDER BY id DESC";
        $stmt = $this->conn->prepare($sql);
        $stmt->execute();
        return $stmt->fetchAll();
    }

    // Lấy 1 user theo ID
    public function getById($id) {
        $sql = "SELECT * FROM " . $this->table . " WHERE id = :id LIMIT 1";
        $stmt = $this->conn->prepare($sql);
        $stmt->bindParam(":id", $id, PDO::PARAM_INT);
        $stmt->execute();
        return $stmt->fetch();
    }

    // Thêm mới user
    public function insert($data) {
        $sql = "INSERT INTO " . $this->table . " (name, email, phone, status, created_at) 
                VALUES (:name, :email, :phone, :status, NOW())";
        
        $stmt = $this->conn->prepare($sql);
        $stmt->bindParam(":name", $data['name']);
        $stmt->bindParam(":email", $data['email']);
        $stmt->bindParam(":phone", $data['phone']);
        $stmt->bindParam(":status", $data['status']);
        
        return $stmt->execute();
    }

    // Cập nhật user
    public function update($id, $data) {
        $sql = "UPDATE " . $this->table . " 
                SET name = :name, 
                    email = :email, 
                    phone = :phone, 
                    status = :status 
                WHERE id = :id";
        
        $stmt = $this->conn->prepare($sql);
        $stmt->bindParam(":name", $data['name']);
        $stmt->bindParam(":email", $data['email']);
        $stmt->bindParam(":phone", $data['phone']);
        $stmt->bindParam(":status", $data['status']);
        $stmt->bindParam(":id", $id, PDO::PARAM_INT);
        
        return $stmt->execute();
    }

    // Xóa user
    public function delete($id) {
        $sql = "DELETE FROM " . $this->table . " WHERE id = :id";
        $stmt = $this->conn->prepare($sql);
        $stmt->bindParam(":id", $id, PDO::PARAM_INT);
        return $stmt->execute();
    }
}
?>
Lưu ý: Trong thực tế, bạn nên thêm kiểm tra dữ liệu (validation) và xử lý lỗi trong Model hoặc Service layer. Các hàm trên sử dụng Prepared Statements để tránh SQL Injection.

★ SQL Injection là gì? Tại sao phải dùng Prepared Statement?

SQL Injection là một trong những lỗ hổng bảo mật nghiêm trọng nhất trong lập trình web. Đây là kỹ thuật tấn công mà hacker chèn thêm mã SQL vào các trường nhập liệu (form) để thao túng câu truy vấn database.

Ví dụ bị tấn công SQL Injection

Giả sử code viết theo cách nguy hiểm sau: 

<?php
// ❌ Cách viết NGUY HIỂM (Dễ bị SQL Injection)
$id = $_GET['id'];   // Người dùng truyền vào

$sql = "SELECT * FROM users WHERE id = $id";
$stmt = $conn->query($sql);   // Không có prepare
?>

Nếu hacker nhập vào thanh địa chỉ:

1 OR 1=1 --

Câu SQL sẽ trở thành:

SELECT * FROM users WHERE id = 1 OR 1=1 --
Kết quả: Hacker lấy được toàn bộ thông tin user trong bảng!
Họ còn có thể xóa dữ liệu bằng cách nhập: 1; DROP TABLE users; --

Cách phòng tránh bằng Prepared Statement 

<?php
// ✅ Cách viết AN TOÀN với PDO
$id = $_GET['id'];

$sql = "SELECT * FROM users WHERE id = :id";
$stmt = $pdo->prepare($sql);        // Chuẩn bị câu lệnh
$stmt->bindParam(":id", $id, PDO::PARAM_INT);  // Gắn giá trị
$stmt->execute();

$user = $stmt->fetch();
?>

prepare() làm gì?

Tách biệt cấu trúc SQL với dữ liệu. Server sẽ phân tích cú pháp SQL trước, sau đó mới nhận dữ liệu.

bindParam() làm gì?

Gửi dữ liệu riêng biệt, không cho phép dữ liệu được coi là một phần của câu lệnh SQL. Dù hacker nhập gì, nó cũng chỉ là dữ liệu, không phải lệnh SQL.

Kết luận: Luôn luôn sử dụng prepare() + bindParam() hoặc bindValue() khi làm việc với dữ liệu từ người dùng. Đây là cách bảo mật cơ bản và quan trọng nhất khi làm việc với Database.
